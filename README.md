# JadeHybrid 0908 独立版

本目录是独立版本。源码、内存桥源码、构建输出、测试工程都在本目录内；不依赖修改旁边的 `jade混合版` 或 `jadehook`。

在易语言中预览 HTML，点击网页控件生成事件回调和订阅，减少界面与代码之间的重复操作。生成的是事件框架，实际业务逻辑仍由开发者编写。

## 点击行为

- 普通网页按钮、选择框：缺少回调或订阅时，直接修改易语言的项目模型，完整写入并校验，保持当前网页预览，不先打开代码页。
- 回调和订阅均已存在：保留原有定位跳转行为，不重复创建。
- 后台首次创建并校验成功后，预览右上角显示“xxx 子程序已创建”，3 秒自动消失，不抢焦点、不拦截点击；已有回调仅补订阅时显示“xxx 订阅已补齐”。重复点击跳转不弹提示，失败不显示成功提示。
- 程序集未打开、代码超过可见范围、重新启动 IDE：均从项目模型读取并判重，不把未打开的页面当成不存在。
- 支持默认 `Jade_通讯_订阅集`、`UI_JadeView` 以及 `data-jade-assembly` 指定的程序集；订阅统一放在 `Jade_通讯_订阅集.Jade_通讯_订阅`。
- 明确标注 `JadeView.App.注册事件` 的原生生命周期配置仍保留继承的专用流程，不属于本轮普通网页控件后台创建的改造范围。

## 一键生成公共代码

点击预览右下角的扳手图标，选择“公共代码”，再点击“预览公共代码”。入口由支持库统一注入，不要求修改 HTML。先查看候选源码和检查报告，点击“确认生成”才写入工程。

- 创建独立 `Jade_公共基础`：启动、初始化就绪、主窗口、窗口/视窗设置、全部窗口关闭、最小化、最大化切换、关闭窗口，以及生成配置标记。
- 默认窗口 1280×800，不透明；网页从程序旁的 `web` 目录加载。未启用托盘时，页面最小化命令仍是真正最小化。
- 没有 `Jade_通讯_订阅集.Jade_通讯_订阅` 时补建空入口；已有订阅和回调保持不变。就绪后先订阅，再创建窗口。
- 首次写入不切换代码页，写后校验，一次撤销可恢复。重复生成保留用户修改；同名冲突或已有窗口控制通道时停止，不接管原有逻辑。
- 不生成获客、获取 CK、线程、账号等业务代码。

“公共代码”面板内可勾选**托盘常驻**、**单实例**，均默认关闭；设置不再常驻覆盖网页：

- 托盘：单击或双击显示主窗口，右键“显示主窗口 / 退出程序”；页面最小化命令在主窗口且托盘就绪时改为隐藏，隐藏失败则普通最小化。关闭主窗口时，仅在托盘就绪且隐藏成功时取消关闭；退出菜单走真正退出，子窗口仍正常关闭。
- 托盘事件使用 `类_json` 的 `解析`、`取通用属性`、`取属性数值`，不依赖 zyJsonValue。参考工程中该类由精易模块提供；生成前检查类是否存在。当前模块实现还依赖系统 ScriptControl，运行时解析自检失败不启用托盘；事件解析失败则恢复窗口并撤掉托盘。
- 运行目录需有有效 `app.ico`。缺图标、菜单或托盘创建失败时保留正常窗口，不启用关闭到托盘。
- 显示主窗口只调用 `JadeView.窗口.设置窗口显示或隐藏 (窗口ID, 真)` 和 `设置焦点`，不获取 HWND，不再生成 `ShowWindowAsync` 声明或调用。系统标题栏或外部操作造成的真正最小化，不承诺由这两个命令还原；可由任务栏恢复。状态并发保护仍保留两个 Interlocked API。
- 单实例第二次启动请求显示并聚焦现有主窗口；初始化返回假时不进入第二个消息循环。应用标识留空时按当前已保存工程路径生成，可手工指定 6～64 位 ASCII 字母、数字、下划线、短横线。不同软件应使用不同标识；复制工程作为另一软件时请更换标识。
- 再次生成遇到不同模板版本、选项或应用标识，明确拒绝覆盖，不声称已升级。已修改的公共代码需人工合并；刚生成而未修改的代码可先撤销再重选。原有启动入口不变。

**生成后仍需接入启动入口**：先导入匹配的 `JadeView.ec`，将 `jadeview_x86.dll` 和 `web` 放到运行目录，在你确定的启动入口调用 `Jade_公共_启动 ()`。生成器不修改 `_启动子程序` 或 `_启动窗口`，已有 JadeView 初始化的项目不要再重复调用此启动过程。存在 `_启动窗口` 时，不能假定 `_启动子程序` 会执行。

窗口 IPC 通道为 `win:minimize`、`win:maximize`、`win:close`。前端需要调用对应 `jade.invoke`，本功能不会重写网页 JS。已有这些通道的项目需人工整合，避免改变原有窗口行为。

模板参考 [JadeView 易语言快速开始](https://jade.run/easy-language-sdk/quickstart) 和用户提供程序集的通用部分。生成的源码位于 `src/CommonCode.h`，不包含用户参考工程的业务代码。需配套更新 FNE 和带 `JadeHookEnsureCommonAnsi` 导出的 DLL；仅复制 FNE 会明确报告缺少接口。

## 构建

需要 Windows、Visual Studio C++ 工具链（项目使用 v145）、Windows SDK、PowerShell 和 Node.js 22。运行预览还需要 Microsoft Edge WebView2 Runtime。支持库和内存桥均构建为 x86。

在本目录执行：

```powershell
cd designer-tools
npm ci
cd ..
./build.ps1
```

脚本先从 `designer-tools/` 打包注入脚本，再自动寻找 Visual Studio/MSBuild，构建 x86 内存桥、执行判重、桥接口、模板及文字保存测试，最后构建支持库；不会部署到其他目录。`src/DesignerToolsScript.h` 是生成文件，不应手工修改。完整浏览器测试在 `designer-tools/` 执行 `npm test`，需要安装 Microsoft Edge；截图输出到 `bin/tests/screenshots/`。

## 事件绑定与文字编辑

这些工具由支持库注入，不需要复制到每个业务网页。默认仅显示右下角 40×40 的扳手图标；点击打开工具菜单，选择功能后菜单自动收起，同一时间只显示一个面板。菜单外点击仍会执行网页操作；关闭面板或按 Esc 可回到网页。

- **事件绑定**：列出当前 DOM 控件、回调、程序集、频道和状态，可筛选、定位或逐项补齐。检查从 IDE 项目内存读取，不滚动代码页、不走剪贴板。只检查回调与订阅是否存在，不代表业务代码已经编译或执行成功。
- “只补缺失项”成功后仅重新核对并更新当前行，保留整个表格、筛选条件和滚动位置；只有主动点“重新检查”才重建列表。失败显示在当前行，不自动重试。
- 未点击且没有显式频道的控件显示“待观察”，不猜测它会调用哪个频道。实际捕获的频道随本次页面会话记录；动态状态有多个频道时分别展示。重载页面后重新观察。最多显示 500 个 DOM 控件。
- 重复回调、同频道指向其他回调、无法完成读取时不提供自动补齐。补齐前重新检查；保留用户回调正文，不做批量删除或重命名。
- **公共代码预览**：提供候选模板和当前代码对照。已有公共代码只读展示，仍需人工合并，不是自动升级功能。兼容检查尝试核验当前工程内存中所需方法的名称及参数数量；读不到或签名不匹配时不允许确认生成。它不验证方法实现、参数类型、运行 DLL 版本或外部依赖的实际运行情况。
- **编辑文字**：在工具菜单勾选后双击按钮、标题或标签中的单一静态文字节点，填写新文字，再选择“保存到 HTML”。支持按钮旁有图标的情况，保留图标、ID、CSS 类名、频道和回调名。编辑模式会拦截常规网页点击和键盘操作；扳手图标变为绿色状态，取消勾选回到事件模式，按 Esc 则退出到预览模式。网页自己提前注册的窗口捕获监听、定时器和网络任务不在此隔离范围内。
- 只保存当前工程 `web/index.html` 中能由 HTML 解析器准确定位的文字；仅接受 UTF-8、2 MB 以内的普通文件。脚本、样式、模板、输入值、多个混合文字节点或与源文件不一致的动态文案拒绝编辑，不猜着改 JS/CSS。JS 在后续状态切换时仍可能重新设置标签，这种情况需修改 JS 的文案源。
- 每次保存前比较完整源文件；被外部改动或位置过期时拒绝覆盖。保存前在 HTML 旁创建 `index.html.jade-*.bak` 备份。工具栏撤销箭头仅撤销当前会话最后一次文字修改，并在撤销前再次检查文件；备份可以人工保留或清理。工程切换和页面导航会使待处理操作过期。

文字保存与浏览器行为已用隔离测试验证；实际 IDE 模块检查、生成和定位仍需在工程副本中回归。测试不覆盖任意框架动态 DOM，不能保证所有网页都可直接编辑。

## 可视化设计（基础版）

扳手菜单提供“设计 / 事件 / 预览”三段模式，以及“可视化设计”入口。初次默认事件模式；同一标签页按网页路径记住模式，刷新后不把预览模式突然变回事件模式。

- **设计**：点击网页控件只选中，不触发常规网页业务或自动生成代码。切换到设计模式不弹出属性面板；只有点击“可视化设计”入口才打开。面板打开后，也可从“选择控件”列表选中，使用向上箭头选择父级标签或区域。
- **事件**：保持原来的点击生成、缺项补齐和已有回调定位；网页自己的点击逻辑仍执行。
- **预览**：执行网页本身操作，但不发送自动创建/定位事件。这里仍是 IDE 的网页预览环境，不是实际主程序业务联调通过的证明。显式“确认生成”“只补缺失项”等管理命令不受此模式开关限制。
- Esc 关闭面板并从设计返回预览；关闭面板的 X 只收起面板，不结束设计模式。页面自己更早注册的 window 捕获监听、定时器、网络任务不在设计模式的隔离保证内。
- 面板关闭后，再次选中控件、启用组件箱或添加控件不会把它自动弹出；延迟的读取回执也不会重新打开已关闭面板。面板关闭时添加成功或失败使用不抢焦点的短提示。“提取元素描述”仍通过自己的显式入口打开描述面板。

### 属性与保存

- 支持单一静态标题、宽高（自动/铺满/像素）、字号、文字/背景颜色、隐藏（保留布局位置）、禁用；输入框支持提示、只读、非密码普通输入框的默认内容和勾选框默认状态；简单下拉框支持默认选项。
- 可选中控件设置横向/纵向偏移，或用四向箭头按步长微调；点击“保存属性”才应用并写入 HTML，可重置或撤销。使用独立 CSS `translate`，不覆盖已有 `transform`；保留原布局占位，移动过远可能重叠，并非自由拖拽或自动重排。只开放可变换盒子和可解析的整数像素位移，范围为正负 2000 像素。
- 布局容器支持左右/上下排列、间距和内边距。原有任意布局不会自动重排；选中排列选项才写入 flex 布局。
- 点击“保存属性”才落盘并更新预览。多个属性和标题一起保存、一起撤销；不逐次键入就写文件，也不整页重载。保留原节点和事件监听，保留 ID、回调名、频道、原有脚本及未修改的属性。
- 尺寸和颜色作为严格限定的行内声明追加，优先于现有样式；不猜测修改外部 CSS。密码默认内容不提供编辑。原有标题来自多个节点、脚本或运行状态时不强行改写；可以选中独立文字标签或继续使用静态文字编辑。
- 来源必须是当前 `web/index.html`、UTF-8、2 MB 内普通文件。parse5 对应源码位置，原生端再次限定标签、属性、样式值和写入范围；隐式/不明确的 HTML 结构、重复标识、无法区分的匿名控件、模板与框架内部元素拒绝编辑。写前比较整份原文件，备份后再写；外部修改时拒绝覆盖。
- 匿名容器结合最近唯一 ID 所属区域及内部控件 ID 定位，不再因其他区域存在同样的布局标签而拒绝添加；同一区域内仍无法区分的相同节点、重复 ID 或动态变化仍会拒绝，避免写错区域。

### 标准控件

“控件”页目前提供 **10 种**：按钮、标签、标题、输入框、多行输入、复选框、单选框、下拉框、布局容器、进度条。选择追加到当前布局容器或页面末尾；这是规则布局添加，不是自由坐标拖拽。

### 易语言组件箱位置

扳手菜单增加 **“使用易语言组件箱”**，默认关闭。同一网页标签页记住选择；勾选后进入设计模式，在易语言原“基本组件”位置显示“Jade 网页组件”。属性编辑仍在网页右侧，不接管原生属性窗口。

- 先选一种网页控件，再单击网页中的区域，追加到所点的最近布局容器末尾。选择列表本身不写 HTML；落点仍按页面布局排列，不是像素坐标绘制。选“指针”取消待添加控件。
- 保持勾选时，在 Jade 网页内切换设计/事件/预览模式均保留 Jade 组件箱；事件/预览模式仅禁用添加列表，返回设计即可继续。切离 Jade 网页到原生文档、取消勾选或卸载支持库时恢复原列表。原组件树不删除、不改内容、不改命令；原来隐藏的子控件不会被误显示。插件临时打开的组件箱在退出接管时恢复原隐藏状态。
- 通过同一 IDE 进程、同一 UI 线程内的组件箱窗口结构、控件 ID、类名和标题共同识别。使用公开的 `FN_SWITCH_UNIT_BAR` 接口尝试展开组件箱，不修改易语言二进制。工程没有原生窗口、组件箱不能展开或不能唯一识别时，显示独立的“Jade 网页组件”浮动窗口，不再要求先创建原生窗口，不接管其他面板。
- 独立组件箱可移动和调整大小，由 IDE 持有，不是工程里的易语言窗口；切离网页时关闭，返回时恢复。关闭浮动组件箱会取消本页接管选择。事件/预览模式下仍保留，但禁用添加操作。
- 手动关闭组件箱会取消本页接管选择，不持续强制打开。新增控件继续使用相同的名称检查、源码定位、备份和一次撤销流程；不会创建易语言原生按钮或改动 `.e` 的窗口布局。

- 为新增控件分配唯一 ID；按钮、复选框、单选框、下拉框同时生成中文回调名和显式频道。先避开当前 HTML/DOM 的名称，再从 IDE 项目内存核验回调和静态订阅频道；写入前再次核验。读取不确定时拒绝新增带事件的控件，不使用备用读取，也不自动接管旧回调。
- 新控件自己的 HTML 会包含固定的 `jade.invoke` 点击/改变绑定，传递 `value` 和 `checked`，既能在设计器生成回调，也能在 JadeView 运行环境发送消息；不会只在设计预览中有效。现有 HTML 的 JS、已有控件和易语言业务正文不改。严格 CSP 禁止行内事件的网页不保证这些新增绑定能运行，应手工接入页面自身的事件管理。
- 新增输入框、多行输入、标签、容器等不自动生成业务回调；它们的表单提交需要后续接线。单选框默认使用 `jade_radio_group` 一组；下拉框初始三项，当前只支持默认选项设置，选项增删和分组尚未提供。
- 新控件目前使用基础模板，不会自动识别或复制页面主题。字体继承页面，文字/背景等受页面适用的 CSS 和浏览器默认样式影响；专用的 `.btn` 等类不会自动复制，容器边框等有固定初始值。可在属性面板单独调整颜色。
- 暂未提供控件复制/删除、任意拖拽、表格配置器、选项卡和弹窗向导；也不声称任意框架页面都能双向编辑。旧的 HTML 一次撤销机制现在同样可撤销最后一组属性修改或控件添加，仍不是多级历史。

浏览器回归覆盖模式隔离/重载保留、120 行事件表原位补齐、静态属性保存、失败不覆盖预览、重复添加的唯一标识、原生组件箱选择到网页落点、原生生成的控件模板和桌面/窄屏布局。原生组件箱测试使用隔离的 Win32 模拟窗口，验证匹配、选择、缩放、隐藏状态恢复、父窗口销毁及重复退出。先运行 `build.ps1` 编译本机测试程序，再在 `designer-tools` 执行 `npm test`；未编译本机程序时，原生模板的浏览器联测会跳过。真实易语言工程副本仍需回归。

### 元素描述给 AI

- 预览时从扳手菜单选择“提取元素描述”，再单击目标；这一次点击仅提取，不执行页面按钮事件。可按 Esc 取消；提取结束后普通预览点击仍执行原有页面行为，不把预览永久改成选中模式。
- 可视化设计中选中控件后，切到“AI 描述”；也可使用面板里的选择列表、父级箭头或“点选元素”。填写“修改要求”，点击“复制给 AI”后自行粘贴到 AI 对话，插件不向外部 AI 自动发送内容。
- 描述包括文件及可核实的 HTML 行列、选择器、父级区域、可见标题、标识、显式回调/频道、视口位置、计算样式及页面引用的 CSS/JS。动态元素或源码不匹配时只报告运行时信息，不猜测 JS 来源、CSS 规则行号或事件是否有业务作用。
- 不采集密码和表单当前值、完整 DOM 子树或脚本正文；可见标题和选中元素的标识仍可能包含业务信息，发送前应在描述框中检查。此功能不修改 HTML、JS、CSS 或易语言代码。

## 项目体检与通信诊断

右下角扳手菜单内提供“项目体检”“通信诊断”。这些入口仍由支持库注入，不要求业务网页提前添加按钮。

### 项目体检

- 全程只读：从工程内存检查公共程序集、启动子程序、模板标记、订阅入口、重复频道和目标回调。子程序按工程全局名称读取，能区分未找到与无法读取，不打开代码页、不使用剪贴板。
- `_启动子程序`、`_启动窗口_创建完毕` 只检查是否存在直接的 `Jade_公共_启动 ()` 调用；即使找到也标为“未核验”，因为入口优先级、条件分支、间接调用和运行次数不能仅据这行代码确定。不自动插入启动调用。
- 每次检查最多 300 条订阅；不声称完整分析所有程序集、动态频道或完整调用图。模板 v3 标记不代表用户正文与模板相同。
- 检查当前 DOM 重复 id；动态频道和 HTML 到回调的对应关系继续使用“事件绑定”逐项核对。工程旁 `web/index.html`、`jadeview_x86.dll`、`app.ico` 只检查存在性，实际编译输出目录、DLL 版本、图标有效性未运行核验，未启用托盘时不需要 `app.ico`。

### 两种诊断

- **设计器链路**：记录网页事件送入生成器、生成器处理结果及耗时。通过请求编号关联，即使连续点击也不按应答先后顺序猜测；超过 20 秒仍无应答只显示状态未知，不自动重试。
- **运行网页端**：在“通信诊断”中点击“接入运行诊断”，会备份当前 HTML，在显式 `<head>` 开头插入固定脚本引用，并新增 `web/jade-designer-diagnostics-v1.js`。同名脚本内容不同则拒绝覆盖；没有显式 head 的网页拒绝自动接入。此操作只在用户点击接入时执行。
- 从实际程序重新加载网页，左下角的波形图标打开运行面板。只观察 `jade.invoke` 的调用、Promise 应答／拒绝及耗时，不改参数、接收对象、超时选项、结果或异常原因，不重试请求。Promise 会经过一个诊断用的后续处理链，不保证 Promise 对象身份不变；已缓存的旧 invoke 引用、特殊 thenable、跨 realm Promise 或后续被替换的接口不保证被采集。批量调用只有内部确实经过被包装 invoke 的部分能被观察。
- **收到应答不是业务成功**。主进程收到、回调内部执行和后台任务完成未单独接入；不会显示成已验证。运行脚本检测到设计器标记时显示“预览模拟”，不能用于证明实际程序能运行。CSP 或页面代码阻止脚本加载时也不会有运行采样。
- 两边各保留最多 200 条内存记录，重载即清空；不保存或上传参数、返回正文及异常正文。仅显示频道标识，含 URL／查询串等动态形式会隐藏；频道名本身仍不要包含个人信息或密钥。原有 `JadeDesigner.log` 的记录规则没有因此改变。
- 运行诊断仅供测试，发布前移除 HTML 中带 `data-jade-diagnostics="1"` 的脚本标签，再移除对应 JS 文件。其他业务脚本和易语言回调正文不修改。

本轮构建包含新增只读 `JadeHookReadRoutineCode` 导出，FNE 与 DLL 应一起替换。旧 DLL 缺少该导出时体检报告未核验，不启用备用读取。

### 后续顺序

待真实易语言工程回归这两项后，再进行表单绑定生成、耗时操作模板、动态文案配置、按需公共事件模板。本轮没有实现这四项，也没有自动升级或重写用户业务代码。

完整配套输出：

```text
bin/Release/JadeHybrid.fne
bin/Release/jadehook.dll
```

本版本使用内存 API v3。两份文件必须配套，不能混用旧版 DLL。文件名及库标识保持兼容，安装到同一易语言的 lib 目录会替换旧库，不能同时加载两套。构建脚本仅生成本目录产物；用户要求安装时另行备份并替换配套文件，安装记录保存在 `artifacts/deploy/` 或对应功能的验证目录。

## 安装与 HTML 命名

1. 关闭易语言，备份原有支持库文件，再将上述两份编译输出一起放入易语言的 `lib` 目录。
2. 使用下方指纹对应的 `e5.95.exe` 启动并加载支持库。仅重命名其他版本的 EXE 并不能使其兼容。
3. 将网页入口放在易语言工程旁的 `web/index.html`，先在工程副本中试用。

保留网页原有的 `id`、CSS 和 JS 引用，通过属性指定中文事件名称：

```html
<button id="btn-import" data-jade-handler="导入账号_被单击">导入账号</button>
```

完整规则与可交给 AI 使用的提示词见 [HTML 控件命名规范](docs/AI提示词_HTML控件命名规范.md)。普通浏览器打开网页不会生成易语言代码，需要支持库预览参与。

## 内存路径

读取：项目程序集表 → 子程序表 → IDE 原生源码序列化。

写入：IDE 原生源码解析 → 名称及类型解析 → 项目模型合入/子程序正文插入 → 完整源码校验。一次事件使用一个撤销组，校验失败请求撤销并复核恢复结果。

正常后台创建不调用打开代码页、移动光标、全选、复制、粘贴或模拟键鼠。旧版的活动编辑器读写接口仍保留，供“已存在则跳转”及原生生命周期分支使用；它们同样是纯内存接口，没有备用剪贴板读取。

## 限制与日志

- 仅支持已分析的 x86 `e5.95.exe`，SHA256：`368CBBD323D2C5BC00F0C072B116333F75339FC0742E238D3E5E6FF17ABE1409`。
- 源码单次输入上限 16 MiB；类程序集、只读/调试状态、重入及重复名称等不安全状态拒绝写入。
- 创建后保持网页是本版默认行为，不会根据按钮标题自动重命名已有用户代码。
- 日志仍为当前易语言工程目录下的 `JadeDesigner.log`。`BACKGROUND ensure result=1` 表示本次有修改；`background_callback_created_verified` 表示新建回调，`background_subscription_repaired_verified` 表示仅补订阅；`result=2` 表示完整代码已存在。发送创建提示另记 `PREVIEW creation_notice hr=`。
- 历史“删除程序集闪退”等问题不因本轮功能改造而被宣称全部解决。测试只在工程副本上运行，没有执行业务程序。
