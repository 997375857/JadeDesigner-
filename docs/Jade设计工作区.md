# Jade 设计工作区

## 定位

Jade设计保存界面草稿和 AI 开发任务；Jade预览展示工程的实际网页。
设计稿不执行易语言业务，不替代网页适配器，也不表示后台事件已经接通。
本版借鉴 m3e-canvas 的“结构化草图交给 AI 实现”流程，没有复制其源代码。

保存过的 .e 工程可以打开 Jade设计。未检测到 WPE/Jade 网页标记时，不替换原生属性栏，不显示 Jade预览入口。未保存工程先保存 .e 文件。

## 使用

### 编辑面板

编辑器与组件外观参考 AI获客截图中的黑白风格：白色底面、黑色主按钮、中性细边框和轻阴影，不再添加青绿色或蓝色点缀。按钮、输入框、下拉框、数值框、导航、表格、树、选项卡、进度条和弹窗使用通用组件皮肤。工具栏、侧栏与属性面板使用独立的编辑器颜色，不随设计稿主题变化；已有设计稿的显式颜色不会因为升级而被覆盖，可在配色中选“黑白”。组件库标题显示当前组件/预设总数。

`designer-tools/jade-ui-theme.css` 是可复用样式源文件。AI 开发任务只包含需要改动的颜色和样式，不再内嵌整份 CSS；需要新皮肤时可单独提供此文件。它只负责外观，不实现 Jade 数据控件适配器或业务事件；生成正式网页仍须遵守完整对接规范。新设计稿默认黑白、6px 圆角，节点仍可独立修改。卡片/弹窗里的名称、备注是布局示意，不作为业务字段要求。

完整匹配旧版默认青绿主题的设计稿会在内存中更新为黑白，提示待保存；不会自动覆盖设计稿文件。修改过的自定义主题及单个节点的显式颜色保留。

- 组件：32 项组件/预设，分为按钮、操作输入、数据导航、内容反馈、布局形状，支持搜索、样式缩略图、点击添加和拖入画布。
- 图层：前后排序、拖动排序、显示/隐藏、锁定/解锁、复制；Shift 多选后可组合，组合控件可以一起移动，Alt 可单独选择组内控件。
- 配色：六个强调色预设、浅色/深色，以及页面、控件、文字、边框颜色。颜色是设计稿主题数据，不依赖在线字体或 CDN。
- 形状：全局直角、圆角、柔和、全圆及半径；单个控件可以覆盖圆角或恢复继承。
- 字体：本机字体选择、全局字号、单控件字号和文字对齐。
- 动效：关闭、150 ms、250 ms 样式过渡及试播，不包含页面跳转连线或复杂动画编排。
- AI 对接：整体需求和任务导出；右侧对接页保存按钮中文回调、通讯通道及控件行为说明。

画布支持缩放、适应窗口、抓手/空格拖移、拖动尺寸手柄、键盘微调、复制与撤销重做。滚轮平移、Ctrl+滚轮缩放；图层锁定阻止画布拖动、键盘移动和删除。画布缩放仅影响编辑视图，不让 AI 用 CSS zoom 缩小正式 UI。

选中未锁定的控件后显示八个缩放手柄，四条边也可直接拖动；鼠标显示水平、垂直或对角箭头。左/上边缩放同时更新位置，保持对边固定；最小尺寸为 24，不能拖出画布。缩放画布后手柄保持可点击尺寸，右侧位置和宽高实时更新，完成一次拖动只占一个撤销步骤。

新增的 19 项预设：图标/描边/柔色/文字/悬浮按钮，多行/密码/搜索编辑框、开关、标题、标签徽标、内容卡片、工具栏、侧边导航、窄侧导航、对话框、分隔线、矩形、椭圆。`preset` 保存样式语义，`kind` 保留原来的模块控件类型；并不是新增 19 个易语言类。开关沿用复选框适配，多行/密码/搜索沿用编辑框适配。卡片、导航、对话框等属于布局草稿，子控件与交互由 AI 根据需求实现，当前仍不支持自动嵌套。

侧边导航采用图标在左、文字在右；窄侧导航采用图标在上、文字在下，选中图标带主题色浅底胶囊。右侧可修改每项标题与图标、设置默认选中项、增删选项（1 至 12 项）、开关顶部菜单图标。配置保存为 `navigation` 并随 AI 任务完整导出。导航项 ID 在本导航内稳定，正式 HTML 需用父控件 ID 加子项 ID 组合，避免多导航重复。设计页点击只选择整个组件，不执行页面跳转或易语言业务。

### 交付流程

1. 点击 Jade设计，在组件栏点击或拖入控件，拖动位置；右侧修改文字、位置、尺寸、需求说明。
2. 超级列表框设置列数量、每列标题与宽度、固定行高。界面上的列表只是草稿；正式数据等待易语言插入。
3. 在易语言内点击“编辑现有网页”，把当前工程 `web/index.html` 的原 HTML、CSS 和本地资源载入中央画布，不跳转到另一个编辑器。左侧组件库/图层、右侧属性及缩放工具保持不变。原 DOM 放在隔离 iframe 中，本地样式和图片由 WebView2 映射当前工程 web 目录；不执行原网页脚本或内联事件。点击原控件可选中、修改可识别的静态文字、拖动和调整大小，也可在同一画布添加新组件。独立的静态文字即使没有 ID 也可以选中、修改、复制；不支持的无 ID 结构仍选中已识别祖先。JS 动态内容不能自动还原，复杂文案由 AI 修改。
4. 此操作只保存设计意图，不直接改原 HTML/CSS/JS/WPE。设计稿中 `sourcePage=true` 记录原网页画布，`source=true` 标记原 DOM 控件；重开设计稿会重新载入工程网页并应用草稿修改。AI 任务要求按稳定 ID 增量落实，保留原布局、样式和业务代码。原网页外观不随设计器主题变色。Jade预览仍作为真实网页运行入口。
5. AI 对接面板的“仅导入控件身份”才是旧的 ID、类型、回调和通道提取功能，不还原原布局，不修改原 HTML/JS。独立打开 `artifacts/design-workspace/index.html` 没有易语言工程路径，不能自动读取另一个工程的网页。请在对应易语言工程中使用“编辑现有网页”。
6. 保存后点击“生成 AI 开发任务”，复制或下载简短的增量任务：新增控件、现有控件逐字段修改、明确删除、主题改动。未改控件与整份设计稿不重复输出。任务仅附上本次涉及的数据控件对接要点；完整《AI 生成 UI 与 JadeView 易语言支持库对接规范》保存在 JadeHybrid 源码 `docs` 目录，复杂控件需让 AI 一并读取该文档。若工程的 `web/index.html` 在设计期间被外部修改，导出会提示重新读取和核对，避免按旧网页定位改错内容。
7. AI 增量修改工程 web 文件；返回 Jade预览查看实际页面，已有文件监视逻辑负责刷新。浏览器测试之后仍需易语言实机联调。

### 文字编辑

组件库首组“文字”提供文本、标题和标签徽标；画布工具栏的 T 图标可直接添加文字。新增后可修改“显示文字”、字号、颜色和粗体，也可以拖动、调整大小。选中原网页静态文字再点“复制控件”，副本是独立的新增文本，保留文字、字号、颜色和粗体，不会复用原元素身份。

没有 ID 的原文字使用设计稿内部 ID，并保存 `sourceLocator`（结构选择器与原文）；不会给原网页偷偷写入 ID。重开设计稿使用未改动的原 HTML 恢复定位。AI 落实修改时必须核对选择器与原文，若原文件结构或文字已变化导致不匹配，应停止并说明，不能按内部 ID 猜测替换。文字修改只操作对应文本节点，不覆盖相邻图标、按钮或子结构。

## 文件与安全边界

每个工程独立保存，即使多个 .e 文件位于同一目录也不会串稿：

- `工程.e.jade.design.json`：版本 1 设计稿，包含控件、列、说明、导入基线。
- `工程.e.jade-ai-task.md`：当前导出的增量 AI 任务；完整规范保存在 JadeHybrid 源码仓库的 `docs` 目录。
- 支持库的会话草稿按工程完整路径隔离；切换设计/预览后返回会询问是否恢复未保存草稿。关闭易语言前必须保存到工程，会话缓存不代替文件保存。
- 独立 HTML 版保存时同时保留浏览器本地副本并下载 JSON；重开同一路径可恢复已保存稿。浏览器清理数据会删除本地副本，工程交付以导出文件为准。

版本 1 设计稿兼容旧数据；新增 `theme` 与节点 `style` 为可选字段。节点外观的空值表示继承主题。图层 `hidden`、`locked` 仅是设计器管理状态，不要求运行页面隐藏或禁用；`group` 表达组合布局意图，不增加易语言控件类。

保存比较原文件内容；外部修改、占用、非法路径或超限时拒绝覆盖并显示错误。不改 .e、HTML、WPE，不生成业务数据。单个保存文件限制 1 MB，最多 500 个控件、每个列表 64 列。

控件 ID 创建/导入后在属性面板只读，避免用户不知情地破坏易语言绑定。所有未提及的现有控件与业务代码必须保留。导入基线中被明确删除的控件才进入删除意图。

## 本版边界

- 已实现：独立入口、组件样式缩略图、图层排序/显隐/锁定/复制/组合、配色/形状/字体/样式过渡、缩放/抓手/尺寸手柄、撤销重做、列配置、保存/导入设计稿、读取已有控件身份、AI 完整任务输出、预览切换。
- 尚未实现：任意 HTML 精确反向排版、自动调用 AI、AI 修改结果自动验收、多页面连线、任意嵌套容器编辑。区域控件目前只是平面布局区域，不是可自动容纳子控件的布局引擎。
- 不把“任务已导出”显示成“生成成功/易语言验证通过”。编辑框、独立选择框等事件遵循对接规范当前支持范围。

## 验收

先用原生工程验证无属性接管，再用 UI测试模块.e 验证两个入口。设计页修改并保存，重开恢复；修改磁盘设计稿后再次保存应拒绝覆盖。导出任务应包含全部规范和控件配置。切回预览确认原有属性、通讯诊断、事件跳转保持正常。工程 A 切换到 B 后不得把 A 的设计保存到 B。
