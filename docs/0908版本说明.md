# 0908 版本说明

## 本版范围

- 普通网页按钮、选择框、复选框和单选框缺少回调或订阅时，通过进程内项目模型创建或补齐，保持网页预览。
- 回调及订阅完整存在时，按原流程定位代码，不再重复生成。
- 后台首次创建校验成功后显示“xxx 子程序已创建”；仅补订阅显示“xxx 订阅已补齐”。3 秒自动消失，不抢输入焦点，不拦截鼠标点击。
- 普通后台创建不依赖代码页是否打开或代码是否在可视区域内，不使用备用剪贴板读取。
- 支持中文 `data-jade-handler`、默认程序集、共享程序集和 `data-jade-assembly` 指定的程序集。

## 已执行的验证

2026-09-08 在独立测试工程和复制的 IDE 中完成以下验证，未执行真实业务程序：

- 27 项项目程序集判重测试，以及 API v3 不支持宿主时的保护测试。
- 54 项原生模型回归检查，包括后台创建、重复不写、仅补订阅、118920 字符长页面、跨程序集、撤销重做、线程及忙状态保护、剪贴板和活动编辑器不变。
- 65 项浏览器检查，覆盖含 141 个测试控件的页面；包括事件消息、嵌套弹窗、动态控件、创建提示计时、焦点保持、长中文名称换行和纯文本显示。没有 JS 异常。

浏览器检查使用真实的支持库注入脚本，但原生消息传输经过模拟；原生模型检查单独执行。上述结果不代表任意 HTML 框架或所有易语言版本均已通过测试。本机日志、临时工程和调试产物不随源码发布。

## 兼容性与限制

- 仅适配指定 x86 `e5.95.exe`，SHA256 为 `368CBBD323D2C5BC00F0C072B116333F75339FC0742E238D3E5E6FF17ABE1409`。
- 需要配套 `JadeHybrid.fne` 和 `jadehook.dll`（内存 API v3），不能混用旧 DLL。
- 源码单次输入上限为 16 MiB，不宣称无限长度。
- 只读、调试、重入、重复名称等无法安全修改的状态会拒绝写入。
- 明确标注 `JadeView.App.注册事件` 的原生生命周期配置保留继承的专用流程，不属于普通网页控件后台创建改造范围。
- 回调只提供参数和基础代码，业务功能仍需自行实现。弹窗纯关闭等控件会被过滤；需要业务回调时请核对 HTML 命名规范。
- 尚处测试完善阶段，不宣称历史崩溃等问题已全部修复。建议始终先在工程副本中试用并保留备份。
