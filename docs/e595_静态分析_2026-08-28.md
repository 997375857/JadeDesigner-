- SHA256：`368CBBD323D2C5BC00F0C072B116333F75339FC0742E238D3E5E6FF17ABE1409`
- 文件大小：3,338,240 字节
- 架构：PE32 / Intel 80386 / Win32 GUI
- ImageBase：`0x00400000`
- 入口点 VA：`0x00530527`
- 入口点 RVA：`0x00130527`
- 重定位：已剥离；目标程序按固定首选基址构建

本记录中的 VA 是首选虚拟地址；RVA 为 `VA - 0x00400000`。插件运行时仍应以 `GetModuleHandle(nullptr)` 得到的实际基址换算，不直接假定首选基址。

## 2. 主菜单命令和内部编辑器命令

从 PE 菜单资源和命令映射表确认：

| 功能 | 菜单命令 ID | 内部编辑器命令 |
| --- | ---: | ---: |
| 插入新程序集 | `32782 / 0x800E` | `0x0202000D` |
| 插入新子程序 | `32777 / 0x8009` | `0x02020009` |
| 全选代码页 | `33009 / 0x80F1` | `0x01010023` |
| 复制 | `57634 / 0xE122` | `0x02030001` |
| 粘贴 | `57637 / 0xE125` | `0x02020005` |

菜单资源中的文字分别为：

- `&M.程序集` / `&M.新程序集`
- `&S.子程序` / `&S.新子程序`
- `&F. 全选\tCtrl+A`
- `&C.复制\tCtrl+C`
- `&P.粘贴\tCtrl+V`

结论：作者所说的“主菜单插入程序集，插入以后改代码”具有完整的原生链路。JadeDesigner 不需要再调用 `FN_INSERT_NEW_MOD`、`FN_SET_AND_COMPILE_PRG_ITEM_TEXT` 或 `FN_INSERT_TEXT`。

## 3. 0.11 采用的最小链路

第一阶段暂不直接调用内部 thiscall，优先复用易语言自己的命令路由：

1. 激活一个原生代码 MDI 页面。
2. 向主窗口发送 `WM_COMMAND / 0x800E`，创建新程序集。
3. 向主窗口发送 `WM_COMMAND / 0x80F1` 和 `0xE122`，复制新代码页全文。
4. 在复制文本中把第一条 `.程序集` 声明替换为 `Jade注册事件`。
5. 追加 `.子程序 按钮1_被单击`。
6. 同时写入 `CF_UNICODETEXT` 和 GBK `CF_TEXT`。
7. 发送 `WM_COMMAND / 0x80F1` 和 `0xE125`，由易语言自己的编辑器解析并替换代码页。
8. 再次全选、复制并验证 `.程序集` 和 `.子程序`。
9. 验证失败时，用写入前复制的完整代码页尝试回滚。

该路径仍然是 EIDE 原生编辑器写入，不是对 `.e` 文件离线修改，也没有向 `e.exe` 代码段写内存。

## 7. 0.11 安全约束

- 保留 0.10 源码和压缩包不动，0.11 使用独立目录。
- 第一轮必须新建可丢弃工程。
- 第一轮只点击“按钮1”，测试新建 `Jade注册事件` 和 `按钮1_被单击`。
- 未验证前不要点击“公共 UI”，不要覆盖正式工程中的现有 `UI_JadeView`。
- 日志必须出现：
  - `native_menu begin label=insert_assembly id=32782`
  - `native_write_verify read=1 assembly=1 subroutine=1`
- 如果出现 `native_write_rollback ... matched=0`，立即停止测试并保留工程现场和日志。
